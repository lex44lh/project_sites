# Бриф проекта

Этот репозиторий описывает работу студии. Бриф первой компании появится в её отдельном репозитории после получения материалов.

Для брифа собираем карточку компании, город, услуги и цены, аудиторию, преимущества, цель сайта, структуру страниц, исходные материалы и сценарий MVP. По недостающим сведениям задаём 3–5 вопросов.
