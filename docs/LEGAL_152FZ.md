# Проверка обработки персональных данных

Статус студии: сценарий первой компании ожидает брифа. Файл задаёт состав проверки для её репозитория.

- Определить оператора, цели, необходимые поля и маршрут данных.
- Сверить основания обработки, политику, согласия, cookie и аналитику по фактической схеме.
- Проверить локализацию, доступы, сроки хранения и необходимость уведомлений РКН.
- Зафиксировать итог проверки и ссылки на утверждённые документы перед публикацией сайта.
