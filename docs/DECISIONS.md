## Инструменты

- [Motion Sites](https://motionsites.ai), [UIverse](https://uiverse.io/), [Shots](https://shots.so/) и [Prompt Motion](https://prompt-motion.com) — референсы, интерфейсные компоненты, макеты и анимации.
- ASCN — дополнительный инструмент для SEO. Timeweb — вариант хостинга. Предоставленные PDF используем как справочные материалы по визуалу, публикации и работе с персональными данными.
- LeadGen Base — опциональный инструмент поиска компаний. Предоставленная версия рассчитана на Windows.
- Если согласована поставка в один `index.html`, локальные медиа встраиваем через Data URI, стили и скрипты включаем в файл и проверяем его без соседних ресурсов. Секреты хранятся отдельно, в Git используются плейсхолдеры.

## Порядок работы

Бриф → исследование → технический план → GitHub → дизайн → разработка → упаковка → QA и SEO → публикация → передача. Перед началом задачи каждый агент читает `PROJECT_STATE.md` и `DECISIONS.md` своего проекта. После этапа обновляем состояние и указываем ссылку на PR или коммит.
