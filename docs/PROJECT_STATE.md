# Состояние студии

Обновлено 20.11.2026.

- **Готово.** Для первого проекта собран светлый редакционный сайт с расписанием и приватной демоверсией. Тесты подтверждают блокировку слота, отказ второй пересекающейся заявке и работу обработчика Telegram на тестовых событиях. После обратной связи унифицированы названия услуг и добавлена подсказка о происхождении тестовых дат.
- **Текущий этап.** Приёмка приватного демо владельцем по [задаче № 1](https://github.com/lex44lh/project_sites/issues/1). Имя и телефон на сайте не запрашиваются. Сайт показывает пять тестовых дней, начиная с завтра. Рабочее расписание администратора пока не подключено.
- **Следующий шаг.** После создания отдельного тестового Telegram-бота подключить его токен к локальной тестовой версии и пройти сценарий в Telegram. Доступы, адрес приватного сайта и рабочие данные хранятся отдельно.
